# AI workflow

This document describes the AI workflow used in this project. All codes is in the `crates` directory. Within the `docs` directory, there is `agent` for AI-authored documentation and `human` for human-authored documentation. The `human` directory is broken down further into directories corresponding to human writer. Note, documentation within the `human` directory does not necessarily accurately reflect the current state of the project, and is rather is a place to store the notes for and vision of each human. The `agent` directory has `intended` for planned features and fixes and `fulfilled` for a complete and current documentation of the codebase. Each time the changes described in an `intended` file are completed, the file is deleted and `fulfilled` is adjusted accordingly. An invariant which should hold at every commit is `agent` = `human`. That is to say, if we were to complete all the planned items, the codebase should match all expectations laid out by the human documentation.
