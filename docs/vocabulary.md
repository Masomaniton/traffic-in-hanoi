# Traffic in Hanoi: Vocabulary

This document defines informal vocabulary for conversation and UI copy. It does
not add rules beyond [rules.md](rules.md).

| Term | Meaning |
| --- | --- |
| **dead end** | A partial turn whose final batch is blocked. |
| **burial** | Root-evicting a buried active card, causing a non-active own card to be evicted. |
| **jam** | An opponent-card escape would require an intention with a non-active own card. |
| **undermining** | An intended card's target support becomes evicted. |
| **surfing** | A card fulfils onto opponent cards repeatedly through mix evictions. |
| **target collision** | Two intentions target the same support. |
| **support collision** | An intention targets a card support that is evicted or intended. |
| **mix eviction** | A fulfilled card lands on an opponent-owned card and becomes evicted. |
| **target eviction** | A card occupies a support named by a new intention and becomes evicted. |
| **cover eviction** | A card directly covers an evicted card and becomes evicted. |
